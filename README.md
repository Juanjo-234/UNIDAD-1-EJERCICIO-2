# UNIDAD-1-EJERCICIO-2
Resolución del ejercicio N°1 de la unidad 1 de programación 2.
El programa simula la venta y la reposición de stock de botellas de vino en una bodega.
Para ello primero comprueba que el stock sea mayor a cero y que sea mayor a la cantidad de botellas que se quieren vender.
Después, se tiene un método para reponer botellas, donde se comprueba que la cantidad que se quiere ingresar sea mayor a 0 cero.
Luego, cuando realiza la venta muestra un informe final sobre el stock, el nombre de la empresa y el precio por botellas.
